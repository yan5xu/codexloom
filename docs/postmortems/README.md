# Postmortems

## 如何使用

- 新写 PM 前，先读 `../current/postmortem-process.md`
- 正式 PM 统一使用 `_template.md`
- 这里存放正式事故档案
- 候选卡片如果需要，可放 `discuss/postmortem-candidates/`

## 命名约定

- 有正式 bug / issue 编号时，优先用：`PM-<bug-id>-<slug>.md`
- 没有正式编号时，用：`PM-YYYYMMDD-<slug>.md`
